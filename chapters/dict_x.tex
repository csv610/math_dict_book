\chapter*{X}
\label{chap:x}

\term{X-ray Transform}
The X-ray transform maps a function to its integrals along lines or, in higher dimensions, along selected geometric paths. It is a line-based version of the Radon transform. \par\noindent\textbf{Applications:} it reconstructs internal structure in medical imaging, materials testing, and seismic tomography.

\term{XOR (Exclusive OR)}
XOR, or exclusive OR, is true exactly when one of two inputs is true and the other is false. For bits, it is addition modulo $2$. \par\noindent\textbf{Applications:} XOR is used in digital circuits, error detection, cryptography, and bitwise programming.

\term{x-axis}
The $x$-axis is the horizontal reference axis in the Cartesian plane. It contains points whose $y$-coordinate is zero. \par\noindent\textbf{Applications:} it provides a reference for graphing, coordinate geometry, motion, and data plots.

\term{x-coordinate}
The $x$-coordinate is the first coordinate of a point and measures its signed horizontal position relative to the $y$-axis. \par\noindent\textbf{Applications:} it locates points, represents an independent variable, and describes horizontal motion.
