### Findings

1. **Abel's Theorem — major: conflates distinct results.** The entry combines Abel's limit theorem for power series with the Abel–Ruffini theorem on the general quintic. Separate these under their standard names. For the power-series result, specify radial/within-disk approach to a boundary point where the series converges.
2. **Absolute Continuity — moderate: overstates an application.** Absolute continuity of a function gives an integral representation and an almost-everywhere derivative on an interval; “justifies differentiation under integration” generally needs additional hypotheses for parameter-dependent integrals. Replace that phrase with the fundamental theorem for absolutely continuous functions, or state the required domination/regularity assumptions. Probability densities follow when a probability measure is absolutely continuous with respect to Lebesgue measure, by the Radon–Nikodym theorem.
3. **Adjoint — moderate: missing existence conditions.** The inner-product identity is not guaranteed to define an everywhere-defined adjoint for an arbitrary linear map between arbitrary inner-product spaces. State the finite-dimensional case, or bounded operators between Hilbert spaces (with the appropriate adjoint existence condition).
4. **Affine Variety — moderate: convention and base-field dependence.** A polynomial zero set is an affine algebraic set; “variety” is often reserved for irreducible algebraic sets, and the field matters. State the chosen convention and base field, or use “affine algebraic set” for the broad definition.
5. **Algebraic Closure — minor: “larger” is too absolute.** An already algebraically closed field is its own algebraic closure. Say “an algebraically closed algebraic extension” rather than necessarily “a larger field.”
6. **Almost Everywhere — minor: measure is unspecified.** The definition depends on a chosen measure. The example about changing a function at one point assumes Lebesgue measure on a domain where that singleton is null; it is false for measures that assign positive mass to the point. Name the measure and the needed measurability/integrability assumptions.
7. **Alternating Group — minor: order formula needs a range.** The formula \(|A_n|=n!/2\) should specify \(n\ge2\); for \(n=0\) or \(1\), the group has one element.
8. **Argument Principle — major: contour hypotheses are underspecified.** The formula \(N-P=(2\pi i)^{-1}\int_\gamma f'/f\) as written assumes a positively oriented simple contour enclosing the region and no zeros or poles on it. For general closed curves, zeros and poles must be counted with winding numbers. State the contour and boundary hypotheses.
9. **Artinian Ring — moderate: left/right side is blurred.** The chain condition should say descending chains of left ideals for a left Artinian ring (or right ideals for a right Artinian ring). The Noetherian and nilpotent-radical consequences should retain the unital-ring convention or state it.
10. **Asymptote — moderate: definition is too vague.** “A line or curve that a graph approaches” does not say what limiting behavior qualifies, and “without necessarily reaching it” can imply that intersection disqualifies an asymptote. Define asymptotes through a limiting relation (for example, vertical/horizontal/oblique limits) and note that a graph may intersect an asymptote.
11. **Automorphic Form — moderate: scope and application overreach.** The displayed rule is only a typical upper-half-plane automorphy law and omits the group/action and possible multiplier. The cryptography application is not established by this definition and reads as a direct use; remove it or name a specific, defensible connection. Modular forms are an important special case.
12. **Axiom — minor: “not proved inside” is categorical.** A chosen axiom may be derivable from the rest of a redundant axiom set. Define an axiom as a sentence stipulated as an assumption of a formal system; distinguish independence from being an axiom.
13. **Axiom of Choice — moderate: independence needs a consistency qualification.** Say that, if ZF is consistent, both ZF+AC and ZF+¬AC are relatively consistent with ZF (the standard independence result). “Independent of the other usual ZF axioms” omits this logical qualification.

## B: reviewed entries (44/44)

### Findings

1. **Backward Stability — major: application overclaims reliability.** Backward stability says the computed result is exact for a nearby input (under a specified error measure); it does not by itself ensure a result close to the exact answer for the original input. That also depends on conditioning. Qualify the matrix-algorithm claim and define the perturbation relative to the problem data.
2. **Baire Category Theorem — major: first characterization is false as written.** “Sets with no interior” should be “nowhere-dense sets” (their closures have empty interior). Empty-interior sets need not be nowhere dense. The open-dense intersection formulation is correct for complete metric spaces.
3. **Banach Fixed-Point Theorem — moderate: missing self-map and nonempty-space assumptions.** State that a contraction maps a nonempty complete metric space to itself. Then the unique fixed point and convergence from every starting point follow.
4. **Banach Space — moderate: example is too broad.** Not every space of continuous functions with an unspecified norm is Banach. Name a valid example such as \(C([0,1])\) with the supremum norm, or specify a complete function space.
5. **Basis — moderate: mixes Hamel and topological bases.** The finite linear-combination definition is an algebraic (Hamel) basis. Fourier expansions generally use an orthonormal/Schauder basis and infinite convergent expansions, so qualify that application or distinguish the notions.
6. **Binomial Distribution — moderate: identical-trial assumption missing.** The displayed formula requires independent Bernoulli trials with the same success probability \(p\), not merely independent trials with an unspecified common “success probability.”
7. **Birch--Swinnerton-Dyer Conjecture — major: rank is described imprecisely and the statement is only the rank part.** Define rank as the rank of the finitely generated group \(E(\mathbb Q)\), equivalently the number of independent generators modulo torsion. Equality with the order of vanishing at \(s=1\) is the rank (weak) BSD conjecture; the full conjecture also predicts the leading coefficient.
8. **Birthday Paradox — moderate: probability formula assumptions and range are incomplete.** State that birthdays are independent and uniform over 365 days and that the product formula applies for \(0\le n\le365\) (it is zero for \(n>365\)).
9. **Borel Measure — major: confuses a measure with a particular measure.** A Borel measure is a measure defined on the Borel sigma-algebra; it need not be ordinary length or volume. Present Lebesgue measure restricted to Borel sets as an example.
10. **Borsuk--Ulam Theorem — minor: Earth example needs an idealization.** The theorem requires continuous maps from \(S^2\) to \(\mathbb R^2\). Describe temperature and pressure as idealized continuous fields; actual measurements and weather fields need not satisfy that model exactly.
11. **Bounded Function — minor: range assumptions are unstated.** The order inequalities \(m\le f(x)\le M\) assume a real-valued function. For complex-valued functions, boundedness is stated using \(|f(x)|\le M\).
12. **Bipartite Graph — minor: odd-cycle characterization assumes an undirected graph.** State the graph is undirected; the partition definition itself is fine.
13. **Busy Beaver — major: conflates two different functions.** “Most steps” and “most symbols written” define distinct Busy Beaver functions, commonly denoted separately (for example, \(S(n)\) and \(\Sigma(n)\)). Name the machine model and state-count convention; each standard version grows faster than every computable function.

### Findings

1. **Calculus of Variations — moderate: necessary condition is phrased as a minimizing rule.** The Euler–Lagrange equation is a necessary condition for a sufficiently smooth extremum under suitable hypotheses, not a guarantee of a minimum. State regularity and boundary conditions (commonly fixed endpoints), and say “extremizer” or “stationary curve.”
2. **C*-algebra — moderate: definition narrows the abstract concept.** A C*-algebra need not be introduced as an algebra of operators; abstract C*-algebras are Banach *-algebras satisfying the C*-identity and admit operator representations. Describe the abstract definition, then identify concrete operator algebras as examples.
3. **Category — moderate: “structure-preserving” is not part of the general definition.** A category has objects and morphisms with associative composition and identities. Morphisms are structure-preserving in familiar concrete categories, but arbitrary categories need not have that interpretation.
4. **Cauchy Integral Theorem — moderate: contraction condition needs a domain hypothesis.** The homotopy shrinking the curve must stay inside the domain where the integrand is holomorphic. The stated simply connected-domain version is acceptable with the usual regularity assumptions on the curve.
5. **Cauchy's Integral Formula — moderate: contour and holomorphy hypotheses are incomplete.** State that the function is holomorphic on a region containing the positively oriented simple closed contour and its interior (or give the winding-number version). “Surrounding curve” alone is too weak.
6. **Cayley Graph — moderate: generator convention is unstated.** A Cayley graph depends on a chosen generating set; it is undirected only when the set is closed under inverses. For the integer grid, the standard generators must include both positive and negative coordinate steps (or edges are treated as undirected).
7. **Central Limit Theorem — minor: positive variance is required.** The displayed standardization divides by \(\sigma\), so require \(0<\sigma^2<\infty\) in addition to iid sampling.
8. **Change of Variables Theorem — moderate: “suitable” hides the core assumptions.** State a standard version for a C\(^1\) diffeomorphism between open regions (or an appropriate measurable version), with integrability and the absolute Jacobian determinant. The formula is otherwise correct.
9. **Chaos — major: “encryption” is an overclaim.** Chaotic systems have been proposed in cryptography, but chaos alone does not provide security and many chaos-based schemes are insecure. Remove “encryption” as a direct application or explicitly label it as a research proposal, not an established use.
10. **Characteristic Variety — major: overstates PDE consequences.** The zero set of the principal symbol identifies characteristic covectors. Well-posedness does not generally follow merely from being away from this set, and singularity propagation requires additional hypotheses (for example, real-principal-type conditions). Replace the broad claims with these qualified statements.
11. **Chern Classes — major: “classify bundles” is false in general.** Chern classes are important invariants but do not generally classify complex vector bundles. They classify line bundles via \(c_1\) in standard settings; for higher rank they provide characteristic data, not a complete classification.
12. **Chi-squared Test — moderate: inferential assumptions are missing.** The statistic is standard, but its reference chi-squared distribution is generally an approximation requiring appropriate sampling/independence and sufficiently large expected counts; degrees of freedom depend on the test and fitted parameters. Add a concise qualification.

5. **Delaunay Triangulation — moderate: uniqueness and angle claim need qualification.** Four or more cocircular sites can make the triangulation nonunique. The max-min angle property is for planar point sets and can have ties. State general-position assumptions or acknowledge nonuniqueness.

7. **Deterministic Algorithm — moderate: “others may require randomness” is an unproved necessity claim.** Randomized algorithms are useful for some problems, but randomness being necessary for a particular problem is a complexity-theoretic question. Rephrase to say some algorithms use random bits and compare expected/worst-case analysis.
8. **Diagonal Argument — moderate: decimal construction needs the expansion caveat.** Decimal representations are not unique (for example, terminating decimals also end in repeating 9s). Specify a digit choice that avoids 9 and 0 ambiguities, or use binary expansions with a fixed convention.
9. **Dihedral Group — minor: notation convention varies.** Some sources use \(D_n\) for order \(n\) rather than order \(2n\). State the convention explicitly, as the entry does for its own definition, and avoid presenting it as universal.
10. **Dirac Delta Function — major: generalized function is described as an ordinary function.** No ordinary function is zero away from 0 and has integral 1 while supported at one point. Define \(\delta\) as a distribution (or measure), and make the approximation formula require a normalized approximate identity such as \(\int\phi=1\) with suitable integrability.

Replace it with a specific, supportable use or remove it. The full prevalence will be counted after all letters are scanned.

13. **Weighted Mean — moderate: denominator and weight conventions are missing.** The formula requires Σw_i≠0; a statistical weighted average usually assumes nonnegative weights with positive sum, while signed weights define a different construction. State the intended convention.
14. **Weight (Representation Theory) — moderate: eigenvector condition is incomplete.** A weight is a linear functional λ for which a nonzero vector is a simultaneous eigenvector for a Cartan subalgebra (in the usual setting); not every vector is a weight vector, and weight decompositions require hypotheses. Clarify the definition.
15. **Weil Pairing — moderate: domain and hypotheses are omitted.** The standard pairing is defined on appropriate torsion subgroup schemes/points of an abelian variety (including elliptic curves), with field and torsion-order conditions; it is perfect and alternating in the standard setup. Specify the elliptic-curve case if that is intended.
16. **Weil Transform — major: no single standard transform is identified.** This name is used for different constructions in harmonic analysis and representation theory. Give the defining formula/domain or remove the unsupported general entry.
17. **Well-ordering Principle / Well-Ordering Theorem — major: duplicate and false equivalence in the first entry.** “Every set can be well-ordered” is the well-ordering theorem and is equivalent (in usual foundations) to the axiom of choice. The least-number principle for positive integers is a separate elementary fact and is not equivalent to choice. Separate/correct the entries.
18. **Well-founded Relation — moderate: formulation depends on relation convention and underlying set.** The minimal-element condition applies to every nonempty subset for the chosen strict relation; some authors use the inverse/non-strict relation. State the convention and the set-like relation context.
19. **Weyl Algebra — moderate: characteristic-zero assumption is missing.** The relation [∂,x]=1 has the standard polynomial differential-operator interpretation over a field of characteristic zero; in positive characteristic the resulting algebra has materially different properties. State the coefficient ring/field.
20. **Weyl Character Formula — moderate: Lie-theoretic hypotheses are omitted.** The formula applies to finite-dimensional irreducible highest-weight representations of a semisimple Lie algebra (or corresponding compact/reductive group) with a dominant integral highest weight. Add the setting.
21. **Weyl's Inequality — major: theorem name covers several different results.** Eigenvalue-sum inequalities for Hermitian matrices are a family (e.g. Weyl inequalities); specify the ordered-eigenvalue inequality meant rather than claiming a single unspecified bound.
22. **Weyl's Law — moderate: asymptotic variable and geometric hypotheses are omitted.** The leading eigenvalue-counting asymptotic depends on dimension, volume, operator, and boundary conditions; state the standard Laplacian setting and the counting function rather than saying simply “growth.”
23. **Weyl Tensor — moderate: dimension and physical interpretation are overstated.** The Weyl curvature tensor is the trace-free curvature component (identically zero in dimensions below four in the usual Riemannian setting); its physical role in relativity is not simply “not determined by local matter density.” Qualify the dimension and interpretation.
24. **Whitney Embedding Theorem — minor: manifold conventions are missing.** State the usual smooth, second-countable n-manifold setting and note that 2n is an upper bound on Euclidean embedding dimension (with sharper results in some cases).
25. **Wigner D-matrix — moderate: rotation group and representation index are omitted.** Wigner D-matrices are matrix elements of irreducible representations of SO(3) or its double cover SU(2), with conventions depending on basis and Euler-angle order. Clarify which convention is meant.
26. **Wigner's Semicircle Law — moderate: random-matrix assumptions are omitted.** The limit requires a specified scaling and hypotheses on matrix entries (e.g. independent centered entries with suitable variance/moment bounds); it is not true for arbitrary large symmetric matrices. State a standard Wigner-matrix setting.
27. **Winding Number — moderate: the curve and point conditions are implicit.** The standard integer is defined for a closed curve avoiding the point, with orientation and continuity assumptions; for self-intersections it is a net signed count. State that the point lies outside the curve's image.
28. **Witt Group — moderate: field/ring and characteristic assumptions are omitted.** The classical Witt group is formed from nonsingular quadratic forms over a field of characteristic not 2, modulo hyperbolic forms; there are generalized versions for rings and other forms. Name the setting.
29. **Witt Vector — major: characteristic-zero claim is overgeneralized.** The p-typical Witt-vector construction W(R) depends on a prime p; for an F_p-algebra it is p-adically complete, and W(k) has characteristic zero for perfect fields k of characteristic p, but arbitrary input rings do not make the construction simply a characteristic-zero ring. State the precise case.
30. **Wronskian — moderate: nonzero at one point is not a universal independence test.** Nonzero Wronskian at a point implies linear independence (under differentiability assumptions), but a zero Wronskian need not imply dependence for arbitrary differentiable functions; the equivalence holds for solutions of a common linear ODE under standard hypotheses. Qualify the application.

## Y: reviewed entries (10/10)

Yang--Baxter Equation; Yang--Mills Theory; y-axis; y-coordinate; Y-Delta Transform; y-intercept; Yoneda Lemma; Young Diagram; Young's Inequality; Young Tableau.

### Findings

1. **Yang--Baxter Equation — moderate: analogy is not a mathematical definition.** There are operator, braid, and set-theoretic forms; the operator form is R12 R13 R23 = R23 R13 R12 (up to convention). Specify which form and the spaces on which the operators act.
2. **Yang--Mills Theory — major: mass claim is misleading and confuses open mathematical problems with physical mechanisms.** Yang--Mills theory is a gauge field theory; the Standard Model's W and Z bosons acquire mass through the Higgs mechanism ([U.S. Department of Energy overview](https://www.energy.gov/science/doe-explainsthe-standard-model-particle-physics)). The existence of a mass gap for pure quantum Yang--Mills theory is a separate unsolved mathematical problem ([Clay Mathematics Institute](https://www.claymath.org/millennium/yang-mills-the-maths-gap/)). Replace “predicts that some particles can behave as if they have mass” with a precise, qualified statement.
3. **y-axis / y-coordinate — minor: coordinate interpretation is frame-dependent.** Define the y-axis as x=0 and the y-coordinate as the second coordinate; “vertical” and “height” assume standard Cartesian orientation.
4. **Y-Delta Transform — moderate: equivalence needs a network model and nondegenerate parameters.** The star and delta networks have equivalent terminal behavior for a specified three-terminal resistive network under the transformation formulas; it is not a generic replacement for arbitrary three-branch circuits or components. State the resistive-network setting.
5. **y-intercept — moderate: “crosses” can be false.** The graph may touch the y-axis or have multiple intersections, or none. Define y-intercepts as points of intersection with x=0; a function has a single y-intercept only when its domain includes 0.
6. **Yoneda Lemma — moderate: “understood completely” is overclaiming.** The lemma gives a natural bijection between natural transformations from Hom(A,-) to a functor F and elements of F(A) (covariant form; there is a contravariant form too). It implies an object is determined up to isomorphism by its representable functor, not that every object or relationship is “completely understood.”
7. **Young's Inequality — moderate: exponent and sign assumptions are missing.** The displayed form requires p,q>1 with 1/p+1/q=1 and a,b≥0 (or absolute values for real/complex inputs). Include the conjugate-exponent hypotheses.
8. **Young Tableau — minor: monotonicity depends on tableau convention.** Standard Young tableaux increase strictly across rows and columns; semistandard tableaux use weak rows and strict columns (with convention variants). “Usually increasing” does not distinguish them; name the convention.

## Z: reviewed entries (21/21)

Zappa--Szép Product; Zariski Closure; Zariski Topology; Zeno's Paradoxes; Zero Divisor; Zero-one Law; Zero-point Energy; Zero-set; Zeros of a Function; Zero-sum Game; Zeta Function (Riemann); Zigzag; Z-module; Zonal Polynomial; Zonohedron; Zorn's Lemma; Z-score; Z-test; Z-transform; Zygmund Class; Zygmund's Theorem.

### Findings

1. **Zappa--Szép Product — moderate: mutual actions alone do not define the product.** The two groups must act on each other subject to compatibility (matched-pair) identities. State those conditions or define it via an internal factorization with trivial intersection and unique factorization.
2. **Zariski Closure — moderate: base field and ambient affine/algebraic space are implicit.** It is the intersection of all Zariski-closed sets containing the subset, equivalently the common zero set of all polynomials vanishing on it, relative to a specified field/ambient space. “Adds every point forced by relationships” is only an informal metaphor.
3. **Zariski Topology — minor: “usually large” and “nearness” are misleading.** Closed sets are algebraic zero loci (with field-dependent conventions); the topology is generally not a metric notion of nearness and may fail to be T1 over non-algebraically-closed fields. Replace the metaphor with its actual closed-set definition.
4. **Zeno's Paradoxes — minor: historical summary is too narrow.** The paradoxes are a family of arguments about plurality, motion, and infinity; the dichotomy and Achilles arguments are not simply claims that every trip literally consists of completed steps. Identify the intended paradox and avoid presenting one simplified argument as all of them.
5. **Zero Divisor — moderate: noncommutative ring and unit conventions are omitted.** In a commutative ring, a zero divisor a≠0 satisfies ab=0 for some b≠0. In noncommutative rings one distinguishes left and right zero divisors, and some authors count 0 differently. State the setting.
6. **Zero-one Law — major: no single general law has this definition.** Zero-one laws have theorem-specific hypotheses (for example, tail events in Kolmogorov's law or first-order properties in random graph limit laws); they do not generally say arbitrary statements about large random structures become “always true or always false.” Name the particular law and its assumptions.
7. **Zero-point Energy — moderate: definition conflates a quantum ground state with a universal minimum.** The oscillator formula is correct for the one-dimensional harmonic oscillator, but ground-state energy depends on the system and reference convention; not every quantum system has a positive ground-state energy. State the oscillator example specifically.
8. **Zero-sum Game — moderate: the payoff condition is imprecise for multiple players.** A zero-sum game has payoffs summing to zero for every outcome; a gain by one player need not equal the loss of any single other player when there are three or more players. “Total payoff is zero” is the defining condition.
9. **Zeta Function (Riemann) — major: “analytic function” is false globally and this duplicates an R entry.** The Dirichlet series defines ζ(s) only for Re(s)>1, and it has a meromorphic continuation to the complex plane with a simple pole at s=1. State this domain/continuation distinction and merge/cross-reference the existing “Riemann Zeta Function” entry.
10. **Z-module — minor: notation and scalar-action description are incomplete.** Use ℤ-module consistently; it is an abelian group with an integer scalar action, including zero and negative integers, not only repeated addition by positive integers.
11. **Zonal Polynomial — major: no defining normalization or family is specified.** “Adapted to rotational symmetry” is too vague. In multivariate statistics, zonal polynomials are a particular Jack-polynomial family (often parameter α=2) with normalization conventions. Specify the family/parameter or remove the entry.
12. **Zorn's Lemma — moderate: upper-bound condition is not stated.** The hypothesis is that every chain in a nonempty partially ordered set has an upper bound in that set; then the set has a maximal element. The current wording says “can be extended upward,” which is neither precise nor equivalent in general.
13. **Z-score — minor: standard deviation must be positive and convention identified.** The formula requires σ>0; specify whether μ and σ are population parameters or sample estimates. Standardization does not by itself imply the data are normally distributed.
14. **Z-test — major: description is too narrow and omits distributional assumptions.** Z-tests include tests for means and proportions, often using known variance or large-sample normal approximations. “Difference between averages” is only one case; state the tested parameter and conditions for the normal reference distribution.
15. **Z-transform — moderate: transform convention and convergence region are omitted.** The bilateral transform is X(z)=Σ_n x[n]z^{-n}; unilateral forms also occur, and convergence is restricted to a region of the complex plane. State the convention and region of convergence.
16. **Zygmund Class — moderate: class and domain convention are underspecified.** The displayed second-difference condition is a common definition of the Zygmund class Λ_*(or Λ_1) on the real line, with bounds over specified x,h; periodic, local, and higher-dimensional variants exist. Define the domain and whether a global/local seminorm is intended.
17. **Zygmund's Theorem — major: theorem is not identifiable.** There are multiple theorems associated with Zygmund; the sentence gives no exact hypotheses or conclusion and the asserted Fourier-series behavior is too vague to check. Give the theorem's standard name and precise statement or remove it.
18. **Zero-set / Zeros of a Function — minor: duplicate entries.** Both define the set of inputs at which a function vanishes. Keep one canonical entry and cross-reference the other.
